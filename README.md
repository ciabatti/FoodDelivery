## Getting Started

### 1. Download the Dataset

To run the notebook, you must first download the dataset from Kaggle:

[Food Delivery Dataset — Kaggle](https://www.kaggle.com/datasets/gauravmalik26/food-delivery-dataset)

Once downloaded, extract the archive to access the dataset files.

### 2. Upload the Dataset to Google Colab

If you are using Google Colab to run the notebook:

1. Open the notebook in Google Colab.
2. Locate the first code cell, which is responsible for loading the dataset.
3. Upload the `train.csv` file when prompted by that cell.
4. Once the file has been uploaded successfully, execute the notebook cells in order, from the first cell to the last.

### 3. Recommended Runtime

For faster execution, it is recommended to use a GPU runtime in Google Colab, preferably an **NVIDIA T4 GPU or better**.

A GPU can speed up computationally intensive operations, depending on the libraries and algorithms used in the notebook.

### 4. Run the Notebook

After uploading `train.csv`, run all notebook cells sequentially to reproduce the analysis and results.
